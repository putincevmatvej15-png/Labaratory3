# Лабораторная работа №3. Циклические алгоритмы

## Описание

Изучение циклических алгоритмов, операторов цикла и программирование
циклического вычислительного процесса. Решение индивидуальных задач
на двух языках программирования: **C++** (основной) и **Go/Rust**
(дополнительный).

## Задания

**Задание 1.** Вычислить и вывести на экран в виде таблицы значения функции,
заданной графически, на интервале от `Xнач` до `Xкон` с шагом `dx`.
Интервал и шаг задать так, чтобы проверить все ветви программы.

**Задание 2.** Реализовать тест на простоту согласно индивидуальному варианту
(модуль 3):
- вариант 1 — тест Миллера;
- вариант 2 — тест Поклингтона;
- вариант 3 — ГОСТ Р 34.10-94.

**Задание 3.** Математическая сумма: вычислить сумму бесконечного ряда

$$\sum_{n=1}^{\infty} \frac{n^a}{b^n}$$

для `a, b ∈ [1; 10]`. Если ряд расходится — вывести `infinity`,
иначе — несократимую дробь (например, `3/2`).

**Задание 4.** Увлекательная игра: последовательность из `n` чисел
(5 ≤ n ≤ 50 000), игроки по очереди стирают от 1 до `m` чисел
(2 ≤ m ≤ 100) из начала, прибавляя их сумму к счёту.
Дополнительное условие по варианту:
- вариант 1 — нельзя стирать столько же чисел, сколько в своём предыдущем ходе;
- вариант 2 — нельзя стирать столько же чисел, сколько стёр противник.

Вывести `1`, если победил Павел (ходит первым), и `0` — если Вика.

**Задание 5\*.** Задача об остывании чашки кофе в кофейне НГТУ:
промоделировать процесс остывания по закону

$$dT/dt = -r(T_k - T_{sr}),$$

построить таблицы/графики зависимостей, по измерениям температуры
(в неравномерные моменты времени) построить линейную модель и вычислить
статистические критерии адекватности (коэффициенты корреляции и
детерминации, значимость).
